# 🚫 Words-Polish (Polish Censor List)

Zbiór polskich słów niedozwolonych (`words.txt`), przygotowany z myślą o filtrowaniu czatu na serwerach Minecraft oraz botach Discord. 

---

### 🛠️ Jak używać?
1. Pobierz plik `words.txt` z tego repozytorium.
2. Wklej jego zawartość do pliku konfiguracyjnego swojego pluginu odpowiedzialnego za blokowanie wulgaryzmów.
3. Ciesz się czystym czatem na swoim serwerze!
